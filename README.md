# 🏫 IQAC Database Management System

A web-based database management system developed to organize and manage institutional data for the **Internal Quality Assurance Cell (IQAC)**.

The system was developed using **Python Flask** with **PostgreSQL** and was designed around data from the college's existing IQAC database.

## 🎯 Project Overview

The project provides a web-based interface for working with institutional IQAC data instead of managing the information manually across separate files.

It focuses on organizing, storing, and accessing structured college data through a centralized database-backed application.

## 🛠️ Technologies Used

* **Python**
* **Flask**
* **PostgreSQL**
* **HTML**
* **SQL**

## 🗄️ Database

The application uses **PostgreSQL** as its database management system.

The project includes SQL and CSV resources related to the IQAC database used during development.

## 🏗️ Application Structure

The project follows a Flask-based web application structure:

```text
dlbc-iqa-demo/
│
├── IQAC DATABASE CSV/
├── IQAC DATABASE SQL/
├── templates/
│
├── IQAC DATABASE.sql
├── app.py
├── client_documentation.md
├── requirements.txt
└── README.md
```

## ✨ Key Features
